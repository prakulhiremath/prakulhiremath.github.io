# Prakul Hiremath — Personal Research Portfolio

Static website built with HTML and CSS.

## Preview locally
Open `index.html` in a browser. Keep the `assets/` directory beside it.

## Publish with GitHub Pages
1. Create or open the repository you want to publish.
2. Upload the contents of this folder to the repository root.
3. Ensure the entry file is named `index.html`.
4. In GitHub, open Settings → Pages and publish from the `main` branch and `/ (root)`.

## Before publishing
- Add your current CV as `cv.pdf` in the root directory (the CV link is intentionally a placeholder).
- Check the paper statuses, profile URLs, grant details, and IP records before making the site public.
- The page uses Google Fonts when online and falls back to system serif/sans-serif fonts offline.
